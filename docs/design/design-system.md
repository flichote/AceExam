# AceExam 设计系统

> 视觉 token 与设计规范。AceExam 面向大学生备考场景，主色选择**活力橙（amber）** —— 橙 = "成功上岸"的寓意，年轻、有能量，与 CCN（teal 蓝绿）、RehabFlow（indigo 靛蓝）视觉区隔。

## 设计原则

1. **鼓励感**：备考是辛苦的，视觉要传递"你能行"的正向能量
2. **清爽**：信息密度适中，刷题页零干扰
3. **成就可视化**：掌握度、连胜、进度环是视觉重点

## 色彩 Token

### 主色（amber 活力橙）

| Token | 值 | 用途 |
|---|---|---|
| `--primary-500` | `#F59E0B` | 主色：按钮、TabBar 选中、进度环 |
| `--primary-600` | `#D97706` | 按压态、深色强调 |
| `--primary-100` | `#FEF3C7` | 浅色底：标签、提醒条背景 |

### 语义色

| Token | 值 | 用途 |
|---|---|---|
| `--success-500` | `#10B981` | 做对、掌握、通过 |
| `--danger-500` | `#EF4444` | 做错、薄弱、挂科预警 |
| `--warning-500` | `#F59E0B` | 考前提醒、突击模式（与主色同族但语境独立） |
| `--info-500` | `#3B82F6` | 信息提示、链接 |

### 中性色

| Token | 值 | 用途 |
|---|---|---|
| `--neutral-900` | `#1F2937` | 主文字 |
| `--neutral-500` | `#6B7280` | 次要文字 |
| `--neutral-300` | `#D1D5DB` | 分割线、描边 |
| `--neutral-100` | `#F3F4F6` | 页面背景 |

### 状态 → 徽章映射

| 状态 | 徽章色 | 触发 |
|---|---|---|
| 已掌握 | `--success-500` | 连续 3 次做对同类题 |
| 薄弱 | `--danger-500` | 正确率 < 40% |
| 待巩固 | `--warning-500` | 正确率 40%~70% |
| 突击中 | `--primary-500` 描边 | 考前 7 天自动激活 |

### ❌ 禁用条款

- **禁止使用 CCN 的 teal 蓝绿主色**（`#14B8A6` 系）作为 AceExam 任何主色 token
- **禁止使用 RehabFlow 的 indigo 靛蓝主色**（`#6366F1` 系）作为 AceExam 任何主色 token
- 兄弟项目主色仅可出现在"竞品/项目对比"语境，不得进入设计 token

## 字体

| 用途 | 规格 |
|---|---|
| 大标题（页面） | 20px/700 |
| 标题（卡片） | 17px/600 |
| 正文 | 15px/400 |
| 辅助 | 13px/400 |
| 公式 | KaTeX 渲染（跟随正文行高） |

## 圆角 / 阴影 / 间距

| Token | 值 |
|---|---|
| 圆角 | 卡片 16px / 按钮 12px / 标签 8px |
| 阴影 | 卡片 `0 2px 8px rgba(0,0,0,0.06)`；悬浮 `0 4px 16px rgba(0,0,0,0.10)` |
| 间距 | 4px 基准：4/8/12/16/24/32 |
| 布局栅格 | 375px 设计稿，左右 16px 安全边距 |

## 动效

| 场景 | 动效 |
|---|---|
| 做对/做错反馈 | 200ms 缩放 + 颜色过渡 |
| 页面切换 | 300ms 淡入 |
| 进度环更新 | 400ms ease-out |
