# AceExam 页面地图

> 站点地图 + 页面优先级。目标平台：微信小程序优先（随后 App/H5）。

## 信息架构（路由树）

```
AceExam（TabBar 4 个主 Tab）
├── 首页 tab-home
│   ├── 今日任务卡片（倒计时 + 每日任务 + 打卡）
│   ├── 薄弱知识点速览（Top3）
│   └── 继续上次练习入口
├── 刷题 tab-practice
│   ├── 科目/章节选择
│   ├── 题目作答页（单选/多选/填空/大题）
│   │   ├── 提交后 → 结果反馈（对/错）
│   │   └── 错题 → AI 讲解页
│   ├── AI 讲解页（step-by-step + 教材引用块 + 追问）
│   └── 错题本（按知识点分组）
├── 诊断 tab-diagnose
│   ├── 摸底自测（10 题快速定位）
│   ├── 薄弱知识点地图（图谱可视化）
│   └── 诊断报告（薄弱 Top5 + 建议）
├── 我的 tab-mine
│   ├── 学习数据看板（做题量/正确率/掌握度曲线）
│   ├── 备考计划管理（考试科目 + 日期）
│   ├── 会员中心（订阅入口）
│   └── 设置

拍照录题（全局入口，TabBar 中央凸起按钮）
├── 拍照/相册选图
├── 识别确认页（Pix2Text 结果可编辑）
└── 入库 → 加入错题本/练习
```

## 页面优先级

| 优先级 | 页面 | 里程碑 |
|---|---|---|
| P0 | 刷题、AI 讲解、拍照录题、摸底诊断、今日任务 | M2（MVP） |
| P1 | 薄弱图谱、考前突击、数据看板、打卡连胜 | M3 |
| P2 | 排行榜、海报分享、会员中心、设置 | M3+ |

## 全局布局

- **TabBar 4+1**：首页 / 刷题 / 中央拍照按钮 / 诊断 / 我的
- **导航**：主 Tab 内页面堆栈跳转；拍照为独立 modal 流程
- **状态栏**：小程序原生适配，主色系背景

## 关键页面详情

### 刷题页
- 顶部：知识点标签 + 进度（本组题 x/y）
- 中部：题目区（KaTeX 渲染公式）
- 底部：选项 / 作答区；提交按钮
- 反馈态：正确绿色 / 错误红色 + "AI 讲解"按钮

### AI 讲解页
- step-by-step 分步卡片（可折叠）
- 教材引用块（RAG 溯源：教材名 + 章节 + 原文片段）
- 底部："还不懂？追问"输入框（对话式）

### 拍照录题页
- 拍照预览 + 裁剪
- 识别结果区（Markdown/LaTeX 预览，可编辑）
- 标注知识点归属（自动推荐 + 手动调整）
- "确认入库"按钮
