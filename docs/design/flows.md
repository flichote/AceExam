# AceExam 交互流程

> 核心交互流程（角色 → 动作 → 系统响应）+ 验收点 checklist。

## 流程 1：刷题 → 错题 → AI 讲解（主链路）

```
学生 → 刷题页选组 → 作答 → 提交
  ├─ 正确 → 绿色反馈 + 下一题（连续 3 次同类正确 → 标记"已掌握"）
  └─ 错误 → 红色反馈 + 错题入库 → 点击"AI 讲解"
       → 讲解页：step-by-step（基于教材 RAG 溯源）
       → 追问 → 对话式解答
       → 回到错题本/继续刷题
```

**验收点**
- [ ] 公式在题干/选项中正确渲染
- [ ] 错题自动入错题本（带知识点标签）
- [ ] AI 讲解引用教材片段（CitationBlock 可见）
- [ ] 追问有上下文（记得之前的对话）

## 流程 2：拍照录题

```
学生 → 中央拍照按钮 → 拍照/相册 → 裁剪
  → OCR 识别（Pix2Text）→ 识别结果预览（可编辑）
  → 知识点归属（自动推荐 + 手动调整）
  → 确认入库 → 加入错题本/可练习
```

**验收点**
- [ ] 文字+公式混合识别正确（LaTeX 输出可渲染）
- [ ] 识别结果可编辑（兜底手写/模糊）
- [ ] 入库后出现在错题本对应知识点分组

## 流程 3：摸底诊断 → 备考计划

```
学生 → 诊断 Tab → 摸底自测 10 题 → 提交
  → LLM 分析 → 薄弱知识点地图（Top5）
  → 系统生成备考计划（倒计时 + 每日任务）
  → 首页展示今日任务 → 打卡
```

**验收点**
- [ ] 自测题覆盖主要章节
- [ ] 薄弱 Top5 与自测表现一致（可解释）
- [ ] 每日任务量合理（不超负荷，可调整）
- [ ] 打卡状态持久化

## 流程 4：考前突击（M3）

```
考前 7 天自动激活（或手动开启）
  → 高频考点题优先 + 错题回顾 + 模拟卷
  → 首页切换"突击模式"视觉（primary 描边）
```

**验收点**
- [ ] 突击题单 = 高频考点 + 个人错题交集
- [ ] 模拟卷可计时提交评分

## 状态流转速查表

| 知识点状态 | 进入条件 | 离开条件 |
|---|---|---|
| 未接触 | 初始 | 首次做题 |
| 待巩固 | 正确率 40%~70% | 连续 3 次正确 |
| 已掌握 | 连续 3 次正确 | 后续错误率回升 |
| 薄弱 | 正确率 < 40% | 连续 3 次正确 |

## 跨流程约束

- 所有入库操作（错题/识别题）幂等：重复提交不产生重复记录
- AI 讲解一律走 RAG：无引用命中时明确提示"教材未覆盖"，禁止凭空编造
- 打卡/进度写操作走乐观锁，防并发重复
