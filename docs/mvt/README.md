# AceExam — MVT 需求验证包

> **目标**：花最小的代价（< 3 天、< 10 元 API 费）验证核心假设：
> **在校大学生真的需要一个"AI 备考教练"App 吗？会愿意付费吗？**

## 为什么要先做 MVT

- 产品还没写代码，先用 **问卷 + demo 演示** 收集真实反馈
- 通过标准明确，验证结果直接决定 MVP 是否开工
- 避免"做了一年没人用"的经典创业陷阱

## 核心假设（一句话）

> 我猜 **在校大学生** 会因为 **期末复习没方向、挂科焦虑、自学效率低**
> 而使用 **一个能诊断薄弱点、AI 讲解、生成练习题、考前突击的备考教练 App**，
> 并且 **愿意为深度功能月付 9.9~19.9 元**。

## 验证动作（3 步）

| # | 动作 | 工具 | 成本 | 时长 |
|---|---|---|---|---|
| 1 | 发问卷（大学生群体） | 问卷星/腾讯问卷 | 0 元 | 1 天 |
| 2 | 用 DeepSeek 生成 2 个 demo（高数讲解 + 期末速记提纲） | DeepSeek API | ~几元 | 2 小时 |
| 3 | 找 5~10 个大学生访谈/发 demo 给他们看 | 微信/面谈 | 0 元 | 1~2 天 |

## 通过标准（全部满足 → 开 MVP）

- [ ] 问卷 ≥ 30 份有效回收
- [ ] ≥ 50% 受访者表示"想用/很想要"
- [ ] ≥ 30% 受访者对"9.9~19.9 元/月"表示可接受
- [ ] ≥ 3 人看完 demo 后主动说"什么时候能用上？"
