# AceExam PRD — 产品需求文档

> 本文件是 AceExam 需求的唯一事实来源。当前为规划阶段（v0.1），业务代码未开工。

## 1. 背景与目标

### 1.1 背景
在校大学生期末考试季普遍存在"没信心、不知道重点、不会做题、没人讲"的问题。市面产品（作业帮、夸克学习、超星学习通）要么是搜题工具、要么是内容平台，**缺少一个以"通过考试"为目标、全程 AI 陪伴的备考闭环产品**。

### 1.2 产品目标
- **一句话**：帮助在校大学生顺利通过每一科考试
- **用户价值**：考前心里有底 —— 知道考什么、知道哪里弱、不会的有人讲、有计划可执行
- **商业价值**：Freemium 订阅制（创业第一项目，先验证产品价值再谈规模化）

### 1.3 目标用户
| 用户 | 特征 | 核心痛点 |
|---|---|---|
| 大一~大四在校生 | 期末备考季焦虑、自制力一般 | 挂科风险高（高数/英语等公共课） |
| 挂科边缘学生 | 基础薄弱、欠账多 | 不知道从哪补起 |
| 考前突击学生 | 时间紧、要重点 | 押题/高频考点/模拟 |

### 1.4 切入策略
先做**公共科目**（高数、英语），打磨"科目模板"（题集 + 知识点图谱 + AI 讲解），再逐步扩展：线代 → 概率论 → 大物 → 专业科目。

## 2. 核心闭环

```
诊断 → 规划 → 练习 → 讲解 → 突击 → 复盘
```

| 环节 | 解决什么 | 功能落点 |
|---|---|---|
| ① 诊断 | 不知道自己哪里弱 | 摸底自测 → 薄弱知识点地图 |
| ② 规划 | 拖延、没计划 | 倒计时 + 薄弱点 → 每日任务 |
| ③ 练习 | 题海无效率 | 自适应选题刷题 |
| ④ 讲解 | 错题没人讲 | AI step-by-step 讲解（RAG 教材溯源） |
| ⑤ 突击 | 临时抱佛脚 | 考前高频考点 + 错题回顾 + 模拟 |
| ⑥ 复盘 | 看不到进步 | 学习数据看板 |

## 3. 功能分层

### 🟢 第一层：核心闭环（MVP 必做）
| # | 功能 | 说明 | 技术 |
|---|---|---|---|
| 1 | 智能刷题 | 薄弱知识点优先 + 错误率加权选题 | 题库 + 自适应算法（MVP 规则版，后续 IRT/DKT） |
| 2 | AI 解题讲解 | step-by-step，基于用户上传的教材回答（可溯源） | RAG + DeepSeek flash/pro 分级 |
| 3 | 拍照录入错题 | 拍纸质题/试卷 → 自动识别入库 | Pix2Text OCR |
| 4 | 薄弱点诊断 | 自测 → LLM 分析 → 薄弱地图 | 知识点图谱 + LLM |
| 5 | 备考计划 | 倒计时 + 薄弱点 → 每日任务 + 打卡 | 规则引擎 + 调度 |

### 🟡 第二层：体验增强（V1.1）
知识点图谱可视化 / 考前突击模式 / 学习数据看板 / 语音讲解（TTS）/ 打卡连胜

### 🔵 第三层：增长与壁垒（V2）
班级排行榜 / 成绩单海报分享 / UGC 题库共建 / 挂科风险预警

## 4. 题库来源策略

| 阶段 | 方案 | 说明 |
|---|---|---|
| 冷启动 | 经典教材课后题 + 公开历年真题 + 自建题 | 高校期末真题多官方公开流传 |
| 增长 | **UGC 拍照共建** | 学生上传题目，AI 自动解析入库，解决版权灰度 |
| 长期 | 学校/教师合作 | 形成内容壁垒 |

## 5. 商业模式

- **免费**：基础刷题、错题本（获客 + 留存）
- **订阅（会员）**：AI 深度讲解、教材 RAG 答疑、个性化备考计划、考前突击模式
- **成本控制**：DeepSeek flash 主用（便宜）、pro 仅难题；Pix2Text 自部署零 API 费；pgvector 零额外成本

## 6. 角色与权限矩阵

> 注：产品端角色（学生/会员），非 Hermes 开发角色。

| 角色 | 能力 |
|---|---|
| 访客 | 浏览科目、体验少量题 |
| 学生（免费） | 刷题、错题本、拍照录题（限量） |
| 会员（订阅） | AI 讲解、教材 RAG、定制计划、突击模式、不限量 |
